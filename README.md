# AGG lens modelling results

Browsable results for 89 galaxy-scale strong-lensing systems modelled with the AGG
pipeline: EPL + external shear mass, Sersic lens and source light, fit on the g band.

Open `index.html`, or visit the GitHub Pages site for this repository.

This repository holds only the generated figures and the browser page. The pipeline
source lives in a separate private repository and is deliberately not mirrored here.
Everything here is regenerated by `make_site.py --export`, so edits made directly in
this repository will be overwritten on the next publish.
